# Agentic Fact-Checking Architecture: The Journalist's Mind

## Core Cognitive Framework

### **Layer 1: Initial Assessment Agent (The "Smell Test")**

```
Inputs: Raw claim, source, context
Cognitive Process:
├─ Credibility Signals Scanner
│  ├─ Source authority (institutional/individual)
│  ├─ Language markers (hedging, certainty, emotionality)
│  ├─ Specificity vs vagueness
│  └─ Verifiable elements present?
├─ Stakes Evaluator
│  ├─ Potential impact if false
│  ├─ Public interest level
│  └─ Urgency of verification
└─ Pattern Matcher
   ├─ Resembles known disinfo patterns?
   ├─ Timing suspicious? (news cycles, events)
   └─ Too good/bad to be true?

Output: Priority score + Initial skepticism level + Investigation pathway
```

### **Layer 2: Source Evaluation Network**

```
Primary Source Agent:
├─ Authority Assessment
│  ├─ Expertise in domain
│  ├─ Track record on similar claims
│  └─ Institutional credibility
├─ Bias Detection
│  ├─ Financial incentives
│  ├─ Ideological positioning
│  └─ Conflicts of interest
└─ Methodology Examination
   ├─ How did they know this?
   ├─ Data quality/sample size
   └─ Peer review status
```

### **Layer 3: Cross-Verification Engine**

```
Triangulation Agent:
├─ Independent Source Finder
│  ├─ Geographic diversity
│  ├─ Ideological diversity
│  └─ Methodological diversity
├─ Corroboration Analyzer
│  ├─ Direct vs indirect confirmation
│  ├─ Strength of agreement
│  └─ New details vs repetition
└─ Contradiction Detector
   ├─ Conflicting facts
   ├─ Timeline inconsistencies
   └─ Logical impossibilities
```

### **Layer 4: Context & Historical Intelligence**

```
Context Agent:
├─ Historical Pattern Recognition
│  ├─ Previous similar claims
│  ├─ Evolution of narrative
│  └─ Precedent outcomes
├─ Motivation Analysis
│  ├─ Cui bono? (Who benefits?)
│  ├─ Timing analysis
│  └─ Amplification patterns
└─ Missing Information Detector
   ├─ What's conspicuously absent?
   ├─ Unanswered questions
   └─ Access to information barriers
```

### **Layer 5: Evidence Hierarchy Manager**

```
Evidence Weighing System:
Tier 1: Direct, primary evidence
  ├─ First-hand documents
  ├─ Direct observation
  └─ Original data
Tier 2: Expert analysis of primary sources
Tier 3: Credible reporting citing primary
Tier 4: Secondary analysis
Tier 5: Anonymous/unverified claims

Dynamic Weighting:
├─ Multiple Tier 3 sources > Single Tier 2
├─ Context upgrades/downgrades tiers
└─ Contradiction resolution by tier
```

### **Layer 6: Logical Consistency Auditor**

```
Internal Coherence Checker:
├─ Temporal Logic
│  ├─ Timeline feasibility
│  ├─ Causal sequence
│  └─ Duration plausibility
├─ Quantitative Logic
│  ├─ Numbers add up?
│  ├─ Statistical plausibility
│  └─ Scale consistency
└─ Narrative Logic
   ├─ Motivations make sense?
   ├─ Actions align with stated goals?
   └─ Details support or contradict main claim?
```

### **Layer 7: Meta-Analytical Observer**

```
Red Flag Monitor:
├─ Information Warfare Signatures
│  ├─ Coordinated amplification
│  ├─ Bot activity patterns
│  └─ Strategic timing
├─ Cognitive Bias Check (on self)
│  ├─ Confirmation bias alert
│  ├─ Availability heuristic
│  └─ Anchoring on first info
└─ Unknown Unknowns
   ├─ What could we be missing?
   ├─ Access limitations
   └─ Language/cultural barriers
```

### **Layer 8: Confidence Calibration & Output**

```
Certainty Synthesizer:
├─ Evidence Strength Matrix
│  ├─ Quantity of sources
│  ├─ Quality of sources
│  ├─ Independence of sources
│  └─ Directness of evidence
├─ Confidence Level Assignment
│  ├─ Confirmed (multiple independent tier 1-2)
│  ├─ Highly likely (convergent tier 2-3)
│  ├─ Probable (single strong or multiple weak)
│  ├─ Unclear (contradictory evidence)
│  ├─ Unlikely (weak evidence, strong counter)
│  └─ False (definitive counter-evidence)
└─ Caveat Generator
   ├─ What remains uncertain?
   ├─ What could change assessment?
   └─ What needs further investigation?
```

## Dynamic Adaptation Rules

**Situation-Dependent Pathways:**

1. **Breaking News**: Compress timeline, rely more on institutional sources, flag uncertainty prominently
2. **Historical Claim**: Deep dive archives, academic sources, emphasize context
3. **Scientific Claim**: Methodology scrutiny, peer review essential, expert consultation
4. **Political Claim**: Hyper-vigilant for bias, seek opposing perspectives, motivation analysis critical
5. **Statistical Claim**: Data source verification, methodology examination, reproducibility check

**Feedback Loops:**

- Each layer can request deeper investigation from previous layers
- Contradictions trigger escalated verification protocols
- High-stakes claims activate additional verification agents
- Low confidence triggers expanded source search

**Cognitive Safeguards:**

- Regular bias audits on own reasoning
- Devil's advocate agent challenges conclusions
- Uncertainty quantification required
- Revision readiness protocol (new evidence = reassessment)

This architecture operates as a **parallel, iterative system** rather than linear—agents fire simultaneously and continuously update based on new information, mimicking the journalist's intuitive-analytical hybrid thinking.
